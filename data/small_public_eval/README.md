# Small evaluation material

The package includes small accepted summary inputs under results/accepted_summaries, and legacy U4 interfaces under data/interfaces. It does not distribute raw evaluation trajectories or trained checkpoints. No synthetic evaluation data is substituted. Reproduce the publication tables from accepted summaries with the command in the root README. Full neural replication requires the external canonical assets; hosting and access decisions for these excluded assets remain for the project owner. Included public material is released under the root MIT License.
